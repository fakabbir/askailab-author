title: "tag clustering algorithm"
---

**Common Algorithms Used**

- **Hierarchical/Agglomerative Clustering:** Merges tags into a tree of clusters; ideal when the total number of clusters is unknown.
- **K-Means / Extended Vector Space Model:** Partitions tags into K predefined groups using numeric feature representations.
- **Graph-Based & Neighborhood Methods:** Algorithms like KNN directed graphs, Affinity Propagation, or Local Information Passing Clustering (LIPC) connect related tags by local density
