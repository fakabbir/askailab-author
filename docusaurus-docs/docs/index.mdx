## How to read these

Every article is first-person and self-contained: I state the constraint I was working under, do the
arithmetic in the open, then list the failure modes I design against. Where I ran code, I pasted its real
output — including the runs that looked bad. Where a number is an estimate derived from public data rather
than a disclosed figure, I say so at the point of use.

Start with [User Stats](/user-stats) if you want the estimation discipline, [Complete RAG
Tutorial](/complete-rag-tutorial) if you want something to run in the next five minutes, or
[Vector Clocks for CRDT](/vector-clocks-for-crdt) if you want the deepest rabbit hole.
